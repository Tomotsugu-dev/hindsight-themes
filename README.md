# Hindsight themes

Official themes for [Hindsight](https://github.com/Tomotsugu-dev/Hindsight). You can try each theme on the [theme website](https://hindsight.kyosweb.com/themes/) before you download it.

| Theme | Folder |
|---|---|
| Vermillion Cover | [vermillion-cover](vermillion-cover/) |

## Install a theme

1. Download the theme's zip from [Releases](https://github.com/Tomotsugu-dev/hindsight-themes/releases) or the theme website, and unzip it.
2. In Hindsight, open Settings → Appearance → Custom themes, click Import theme, and choose `theme.json`.

## Releases

Each theme is released on its own. The tag is `<id>-<version>`, such as `vermillion-cover-1.0.0`, and the zip holds one folder named after the theme's id.
